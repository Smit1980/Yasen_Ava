# Перенос и развёртывание Yasen_Ava

Этот репозиторий сохраняет визуальный и голосовой профиль аватара Ясень в виде переносимого локального сервиса и
прозрачного настольного приложения.

## Что зафиксировано

- исходный портрет `assets/portrait.webp`;
- 440 000 частиц и 8,2-секундная сборка лица из потока;
- шейдеры свечения, морфинга и реакции на звук;
- мимика губ, глаз, бровей и головы;
- состояния `idle`, `listening`, `thinking`, `speaking`;
- голосовые режимы `clean`, `assistant`, `vocoder`, `choir`;
- стартовый режим `choir`, форма `head`;
- локальный WebSocket-мост, Windows TTS, faster-whisper и диалог через Codex CLI.

Точные значения профиля находятся в `STARTUP_PROFILE.json`. Контрольные суммы ключевых файлов находятся в
`PORTABLE_MANIFEST.json`.

## Постоянный аватар на Windows

Требуются Python 3.11 и Node.js 22+. Первый запуск установки требует интернет.

```bat
setup_windows.bat
desktop.bat
```

Ясень появится в прозрачном квадратном окне вокруг образа, а не поверх всего экрана. За пределами квадрата рабочий
стол и приложения остаются полностью доступны.

| Команда | Действие |
|---|---|
| `Ctrl+Alt+J` | включить/выключить режим управления мышью |
| `Ctrl+Alt+V` | начать/остановить голосовой диалог |
| `Ctrl+Alt+H` | скрыть/показать аватара |
| `Ctrl+Alt+↑` / `Ctrl+Alt+↓` | увеличить/уменьшить образ на 10% |
| `Ctrl+Alt+0` | вернуть масштаб 100% |
| `Shift` + колесо мыши | плавно изменить масштаб образа с шагом 5% |
| `Shift` + левая кнопка мыши | перетащить Ясеня на другое место или экран |
| Значок Ясеня в трее | меню, автозапуск с Windows, перезапуск и выход |

Масштаб регулируется от 55% до 160% и сохраняется между запусками. Положение квадратного окна тоже сохраняется,
поэтому после перезапуска Ясень остаётся на выбранном экране. Те же команды доступны в меню трея и кнопками
`− / 100% / +` в режиме управления.

Автозапуск выключен по умолчанию и включается только вручную через меню трея. Приложение само поднимает Python-мост,
использует только `127.0.0.1:8780/8781` и завершает принадлежащий ему мост при выходе. Если эти порты заняты старой
копией Voice Orb, приложение остановится с ошибкой вместо запуска второго голосового процесса.

Для обычного браузерного режима по-прежнему можно запустить `run.bat`, а затем открыть
`http://127.0.0.1:8780/` в Chrome или Edge.

## Полный голосовой диалог

1. Установите и авторизуйте Codex CLI: `codex login`.
2. После `setup_windows.bat` один раз загрузите модель распознавания:

```bat
.venv\Scripts\python.exe tools\download_stt_model.py
```

После этого модель `small` используется локально и может работать офлайн. Ответы Codex требуют доступной учётной
записи и расходуют её квоту.

## Что намеренно не публикуется

- `data/persona.json` — личная память, характер и история разговоров;
- `.omc/`, логи, кэши Python и локальное виртуальное окружение;
- авторизация Codex и любые токены или учётные данные;
- содержимое поля чтения текста из браузера.

На новом компьютере `data/persona.json` создаётся при первом изменении характера или после первого диалога.

## Камера и жесты

Основной визуал работает локально. Для первого запуска камеры нужен интернет: MediaPipe загружает библиотеку и модели
с `cdn.jsdelivr.net` и `storage.googleapis.com`. Браузер отдельно попросит разрешение на камеру и микрофон.

## Проверка идентичности

После клонирования выполните:

```bat
python tools\verify_portable.py
```

Ожидаемый результат: `Проверка Yasen_Ava: OK`. Проверка нормализует окончания строк, поэтому работает
одинаково после клонирования в Windows, Linux и macOS.
