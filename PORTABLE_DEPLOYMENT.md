# Перенос и развёртывание Yasen_Ava

Этот репозиторий сохраняет визуальный и голосовой профиль аватара Ясень в виде переносимого локального сервиса.

## Что зафиксировано

- исходный портрет `assets/portrait.webp`;
- 440 000 частиц и 8,2-секундная сборка лица из потока;
- шейдеры свечения, морфинга и реакции на звук;
- мимика губ, глаз, бровей и головы;
- состояния `idle`, `listening`, `thinking`, `speaking`;
- голосовые режимы `clean`, `assistant`, `vocoder`, `choir`;
- стартовый режим `choir`, форма `head`;
- локальный WebSocket-мост, Windows TTS, faster-whisper и диалог через Codex CLI.

Точные значения профиля находятся в `STARTUP_PROFILE.json`. Контрольные суммы ключевых файлов находятся в
`PORTABLE_MANIFEST.json`.

## Быстрый запуск на Windows

Требуется Python 3.11 и современный Chrome или Edge.

```bat
setup_windows.bat
run.bat
```

После запуска откройте `http://127.0.0.1:8780/`. HTTP и WebSocket слушают только localhost на портах 8780 и 8781.

## Полный голосовой диалог

1. Установите и авторизуйте Codex CLI: `codex login`.
2. После `setup_windows.bat` один раз загрузите модель распознавания:

```bat
.venv\Scripts\python.exe tools\download_stt_model.py
```

После этого модель `small` используется локально и может работать офлайн. Ответы Codex требуют доступной учётной
записи и расходуют её квоту.

## Что намеренно не публикуется

- `data/persona.json` — личная память, характер и история разговоров;
- `.omc/`, логи, кэши Python и локальное виртуальное окружение;
- авторизация Codex и любые токены или учётные данные;
- содержимое поля чтения текста из браузера.

На новом компьютере `data/persona.json` создаётся при первом изменении характера или после первого диалога.

## Камера и жесты

Основной визуал работает локально. Для первого запуска камеры нужен интернет: MediaPipe загружает библиотеку и модели
с `cdn.jsdelivr.net` и `storage.googleapis.com`. Браузер отдельно попросит разрешение на камеру и микрофон.

## Проверка идентичности

После клонирования выполните:

```bat
python tools\verify_portable.py
```

Ожидаемый результат: `Проверка Yasen_Ava: OK (17 файлов)`. Проверка нормализует окончания строк, поэтому работает
одинаково после клонирования в Windows, Linux и macOS.
