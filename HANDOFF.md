# Ясень: пакет передачи программисту

Этот Git-репозиторий содержит рабочий исходный код текущего аватара Ясень, исследовательскую базу из 14 проектов,
пять визуальных концептов и план пилота моментального голосового общения.

## Что уже есть

- desktop-аватар на Electron + Three.js;
- портрет из 440 000 частиц, состояния и мимика;
- локальный Python-мост, STT через `faster-whisper`, ответы через Codex CLI и TTS;
- текущий последовательный голосовой цикл; документированная задержка ответа около 15–25 секунд;
- база открытых компонентов с лицензиями и прямыми ссылками;
- скрипт выборочного клонирования референсных репозиториев;
- пять PNG-концептов внешнего вида.

## Цель следующего этапа

Сохранить существующий визуальный образ Ясеня и заменить медленный последовательный цикл на постоянную потоковую
сессию с WebRTC, VAD, прерыванием ответа пользователем и потоковой выдачей звука.

Рекомендуемый первый стек:

1. Ясень/Electron/Three.js — визуальный клиент.
2. Pipecat + SmallWebRTC — основной открытый оркестратор пилота.
3. Два сравниваемых речевых контура:
   - speech-to-speech через Realtime API;
   - streaming STT → LLM → streaming TTS.
4. Текущий `faster-whisper` + Codex CLI + Windows TTS — временный резервный режим.

## Начало работы

```powershell
npm install
python -m pip install -r requirements.txt
npm test
npm run check
```

Клонировать только рекомендуемые референсы:

```powershell
.\scripts\clone-reference-projects.ps1 -Group pilot
```

Клонировать конкретный проект:

```powershell
.\scripts\clone-reference-projects.ps1 -Project pipecat
```

## Обязательные границы

- Все локальные сервисы по умолчанию слушают только `127.0.0.1`.
- API-ключи не попадают в renderer, Git, логи или документы; для браузерной сессии выдаётся короткоживущий токен.
- Внешние действия ассистента выполняются только через явное подтверждение пользователя.
- Не переносить код из проектов с несовместимой лицензией без отдельной проверки.
- APEX-UI разрешает использовать MIT-код, но название Apex и брендинг Reznikov Engineering исключены из лицензии.
- Vach не имеет явного файла лицензии: изучать можно, копировать код в продукт нельзя без разрешения правообладателя.

## Критерии пилота

- медиана до первого звука ≤ 1,2 с, p95 ≤ 2 с;
- остановка речи при перебивании ≤ 250 мс;
- восстановление сессии ≤ 3 с;
- отсутствие самопрослушивания и аудиопетель;
- 20 обычных русскоязычных реплик, 5 перебиваний, 5 сценариев с шумом;
- работа резервного режима при недоступности realtime-провайдера.

Оценка 10–15 рабочих дней является архитектурной, а не результатом завершённой интеграции.
