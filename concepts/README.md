# Визуальные концепты Ясеня

| Файл | Концепт | Идея |
| --- | --- | --- |
| `01-neural-ash.png` | Neural Ash | Нейронные ветви ясеня, янтарные искры памяти; основной образ личности. |
| `02-orbital-council.png` | Orbital Council | Орбитальная сеть навыков и агентов; визуализация рассуждения. |
| `03-duplex-pulse.png` | Duplex Pulse | Голубой входящий и янтарный исходящий поток; лучший вариант для full-duplex пилота. |
| `04-memory-grove.png` | Memory Grove | Тёплые огни воспоминаний и цифровая роща; образ компаньона. |
| `05-operator-sentinel.png` | Operator Sentinel | Карточки инструментов и шлюз подтверждения; рабочий/деловой режим. |

Для первого пилота рекомендуется `03-duplex-pulse.png` как динамика состояний, а `01-neural-ash.png` — как базовая
идентичность. Изображения — концепты, не готовые текстуры интерфейса.
