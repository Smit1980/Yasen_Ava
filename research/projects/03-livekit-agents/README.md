# 03 — LiveKit Agents

**Исходники:** https://github.com/livekit/agents

**Документация:** https://docs.livekit.io/agents

**Лицензия:** Apache-2.0 для framework-кода; отдельный `MODEL_LICENSE` для части моделей.

## Что это

Фреймворк серверных realtime-участников с WebRTC-клиентами, подключаемыми STT/LLM/TTS/realtime providers,
диспетчеризацией задач и телефонией.

## Когда выбирать

- нужен удалённый доступ с нескольких устройств;
- планируются комнаты, масштабирование, телефонные звонки;
- требуется готовая транспортная инфраструктура LiveKit.

## Почему не основной пилот

Для одного локального Ясеня это более тяжёлый инфраструктурный выбор, чем Pipecat + SmallWebRTC. Сохранить как вариант
этапа 2 после подтверждения качества диалога.

```powershell
.\scripts\clone-reference-projects.ps1 -Project livekit-agents
```
