# 00 — Ясень

**Статус:** рабочая локальная база пилота. **Исходники:** корень этого репозитория. **Лицензия:** пока не задана.

## Что берём

- Electron-оболочку и прозрачное desktop-окно.
- Three.js-портрет из частиц, мимику, состояния, субтитры и аудиореактивность.
- Существующий Python-мост как место хранения секретов и локальных интеграций.
- Текущий голосовой контур как fallback до прохождения realtime-приёмки.

## Что меняем

Текущий цикл ждёт завершения записи, batch-STT, отдельного запуска Codex CLI и полного TTS; микрофон блокируется на время
ответа. Для живого диалога нужен постоянный streaming transport и barge-in.
