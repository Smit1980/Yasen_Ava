# 05 — Fay

**Исходники:** https://github.com/xszyou/Fay

**Документация:** связана из официального README

**Лицензия:** GPL-3.0.

## Что это

Полный framework цифрового человека на Python: подключаемые LLM, ASR, TTS, память, MCP, прерывания, Web/desktop/
устройства и несколько пользователей. Основная документация преимущественно на китайском.

## Что изучить

- раздельные интерфейсы ASR/TTS/LLM;
- wake-up, interruption и proactive dialogue;
- управление персонажем и памятью;
- архитектуру подключаемого визуального клиента.
