## Что это

Экспериментальный realtime streaming talking-head. README указывает Ubuntu 18.04, PyTorch 1.12.1 и CUDA 11.3.

## Польза

Можно изучить структуру text/voice interaction, talker-модулей и аудиовизуальной синхронизации.

## Ограничения

- старый CUDA/PyTorch-стек;
- документация преимущественно на китайском;
- нет разрешения на коммерческое копирование кода;
- локальная RX 580 не соответствует CUDA-пути проекта.

## Решение

Только исследование. Не включать исходники Vach в продукт без письменного разрешения или появления лицензии.
