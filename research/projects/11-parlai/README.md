# 11 — ParlAI

**Исходники:** https://github.com/facebookresearch/ParlAI

**Документация:** https://parl.ai

**Лицензия:** MIT. **Статус:** архивирован владельцем 2026-07-30, read-only.

## Что это

Исследовательская платформа для обучения и оценки диалоговых моделей и открытых датасетов.

## Польза

- идеи оценки качества диалога;
- воспроизводимые research tasks;
- исторические модели и datasets.

## Решение

Не строить на ParlAI пилот и production runtime. Использовать только как исследовательский источник методик оценки.

```powershell
.\scripts\clone-reference-projects.ps1 -Project parlai
```
